== 🚀 Background

Core rope memory was developed at MIT in the early 1960s for the Apollo
Guidance Computer (AGC). Unlike magnetic core RAM (which was read/write),
rope memory was purely ROM — software was physically woven into it by hand,
making it immune to power loss, radiation, and vibration.

The AGC held roughly 72 KB of rope memory, hand-woven by factory workers
at Raytheon under the direction of MIT engineers. The project lead,
Margaret Hamilton, earned the nickname *"Rope Mother"* for overseeing
this process.

This project replicates that technology at a small scale using modern
off-the-shelf components and an Arduino.

'''

== ⚙️ How It Works

Core rope memory encodes bits using the physical path of a wire:

....
Wire through the center of a core  →  Bit = 1
Wire routed around the outside     →  Bit = 0
....

When a current pulse is sent down the wire (the "word wire"), it induces a
voltage spike in any core it passes through — typically *200–900 mV* with
a 20-turn sense coil on a good ferrite. A preamp amplifies this spike,
a hardware comparator detects it, a pulse stretcher holds the comparator
output long enough for the Arduino to reliably read it, and the Arduino
captures the result.

Cores where the wire was routed around the outside see no induction — they
read as 0. This is entirely passive ROM: no power needed to retain data.

=== Why Pulse Stretching Is Mandatory

The electromagnetic sense pulse at the coil is 200–500 ns wide. After the
preamp and LM393 comparator, the comparator output snaps LOW for only about
that same duration plus parasitic RC — roughly 1–3 µs total. `digitalRead()`
on an Arduino takes ~4 µs per call. Without an explicit pulse stretcher,
whether the Arduino catches each bit is a race condition.

Every real core rope memory — including the AGC itself — used either an RC
integrator on the sense secondary or a strobed latch to hold the sense signal
long enough for the logic to read it. This design uses a Schottky diode + RC +
74HC14 Schmitt-trigger inverter to stretch each comparator output pulse to a
deterministic 20–50 µs, eliminating the race entirely.

[WARNING]
====
*Do not substitute LM358 for LM393.* The LM358 is a general-purpose
op-amp with a 0.3 V/µs slew rate — far too slow to detect sub-microsecond
induction pulses. The LM393 is a dedicated comparator with ~300 ns response
time and is the correct part. They are nearly pin-compatible but not
interchangeable here.
====

[WARNING]
====
*Do not substitute 2N2222 for 2N3904 in the preamp.* Both are NPN
transistors, but the preamp stage uses 2N3904 specifically. The 2N2222 is
used only for the word wire driver. They are different transistors. Order
both.
====

[WARNING]
====
*Ferrite core material matters.* Use type 43 NiZn toroids (FT50-43).
Do *not* use iron-powder cores (T-xx series, usually red/yellow color)
or type 61 ferrite — their permeability is too low and signal will
collapse by 10–16×. Clip-on ferrite chokes (the split kind for cables)
also will not work. Type 43 toroids are typically grey/black in color.
====

[TIP]
====
*No soldering iron?* You can breadboard the entire circuit including
the magnet wire connections. Sand ~5 mm of enamel off each wire end
aggressively, then tightly wrap the bare copper around the leg of a
male header pin or solid-core jumper wire and push that pin into the
breadboard. The connection is less reliable than soldered but works
for prototyping. For a permanent build, tin the ends with a soldering
iron.
====

=== Full Signal Chain

....
[ Arduino Digital Out Pin ]

    [ 1kΩ resistor ]
          │
          ▼

  Collector ──→ [ Word Wire ] ──→ [ 100Ω ] ──→ +5V
  Emitter  ──→ GND
  (1N4148 flyback: anode→Emitter, cathode→+5V)

     [ Word Wire ]
     ├── Through Core 1  (Bit 7 = 1)
     ├── Around  Core 2  (Bit 6 = 0)
     ├── Through Core 3  (Bit 5 = 1)
     └── ... (through all 8 cores)


[ Sense Coil on Core N ]  (20 turns, 30 AWG, twisted-pair leads)
          │
    [ 100nF cap ]  ← AC-couple to block DC
          │
          ▼
  [ 2N3904 Preamp ]  ← common-emitter, gain ~30
  Base → sense signal (via 10kΩ)
  Collector → [ 4.7kΩ ] → +5V
  Emitter → GND
          │
          ▼
  [ LM393 Comparator ]
  (+) input: preamp collector
  (−) input: ~100mV reference (3.3kΩ / 150kΩ divider + 100nF bypass)
  Hysteresis: 1MΩ from output → (+) input
  Output: open-collector → [ 10kΩ pull-up ] → +5V
          │
          ▼
  [ Pulse Stretcher ]
  Schottky diode (anode→LM393 out, cathode→1nF cap to GND)
  1nF cap charged via diode, discharged via 1MΩ to GND
  Output of RC → [ 74HC14 Schmitt inverter ] → [ 74HC14 inverter ] → Arduino pin
          │
          ▼
  [ Arduino Pin (D2–D9) ]
....

=== LM393 Reference Voltage Divider (Revised)

The original 33 kΩ / 1.5 MΩ divider is replaced with a lower-impedance
version that is less susceptible to noise pickup and input-bias-current
drift:

....
5V ──[ 3.3kΩ ]──┬──[ 150kΩ ]── GND
                │
            (−) input of LM393  (~107 mV)
                │
            [ 100nF to GND ]  ← noise bypass
....

Add a *1 MΩ resistor* from the LM393 output to its (+) input for a few mV
of hysteresis. This prevents the output from chattering when the sense signal
slowly crosses the reference threshold.

=== Pulse Stretcher (New — Required)

The sense pulse from the LM393 comparator is only 1–3 µs wide in practice.
`digitalRead()` takes ~4 µs per call, making direct reads unreliable.
The pulse stretcher extends each comparator output LOW event to a
deterministic 20–50 µs so the Arduino can catch it on any sample within
the window.

....
LM393 output (active LOW)
          │
    [ 1N5819 Schottky diode ]
    Anode → LM393 output
    Cathode → Node A
          │
  Node A ─┤── [ 1nF cap ] ── GND
          │
        [ 1MΩ to GND ]  ← discharge resistor (sets stretch = 1nF × 1MΩ = 1ms)
          │
          ▼
  [ 74HC14 Schmitt inverter, pin 1 ]  ← inverts: LOW pulse → HIGH pulse
          │
  [ 74HC14 second inverter, pin 3 ]  ← re-inverts back to active LOW
          │
          ▼
  [ Arduino sense pin D2–D9 ]
....

*Timing:* τ = R × C = 1 MΩ × 1 nF = 1 ms. The 74HC14's Schmitt thresholds
(typically ~1.5 V rising, ~1 V falling on 5V supply) give an effective
stretched output low-time of roughly 0.5–1 ms — far longer than needed, but
harmless because the Arduino resets state between reads. To shorten to ~50 µs,
use 56 kΩ instead of 1 MΩ.

The 1N5819 Schottky diode's low forward voltage (~0.2 V) is important here:
the LM393 open-collector output pulls low to ~0.1–0.2 V, which barely
forward-biases a regular silicon diode (Vf ~0.6 V). Use the Schottky for
guaranteed fast charging of the cap.

[NOTE]
====
The 74HC14 DIP-14 package contains *6 Schmitt-trigger inverters*, so one
chip covers three sense channels (one inverter to stretch, one to
re-invert = 2 per channel). Two 74HC14 chips cover all 8 sense channels
with two gates to spare.
====

'''

== 🔧 Step-by-Step Build Guide

=== Step 1 — Wind the Sense Coils

. Cut 8 lengths of 30 AWG magnet wire, each about 40 cm long.
. Wind *20 tight turns* through the center hole of each ferrite toroid.
  Use tweezers or a blunt needle to thread the wire.
. Route the two leads as a *twisted pair* — twist them together for 5–10 cm
  before connecting to the circuit. This rejects common-mode noise from the
  nearby word wire.
. Scrape the enamel off the last 5 mm of each lead using fine sandpaper
  (400–600 grit). Test with a multimeter in continuity mode — bare copper
  should read ~0 Ω lead-to-lead through the coil.
. *If soldering:* tin the stripped ends with solder, then connect to circuit.
. *If breadboarding:* tightly wrap the stripped end around a male header pin
  leg and push the pin into the breadboard row.
. Label each core 0–7 with a marker or small sticker.

[TIP]
====
Keep turns tight and evenly spaced around the toroid.
Loose, bunched-up windings reduce coupling and introduce stray capacitance.
*Don't exceed ~25 turns* — past this, self-resonance distorts the pulse.
====

'''

=== Step 2 — Weave the Word Wire

Decide what byte you want to store. For example, `10110001` in binary:

|===
|Bit |Core |Value |Wire Routing

|7 |1 |1 |Through center
|6 |2 |0 |Around outside
|5 |3 |1 |Through center
|4 |4 |1 |Through center
|3 |5 |0 |Around outside
|2 |6 |0 |Around outside
|1 |7 |0 |Around outside
|0 |8 |1 |Through center
|===

Take a length of magnet wire and route it through or around each core in
sequence. This wire is your *word wire* — it represents one memory address.

To store multiple bytes, weave additional independent word wires through the
same 8 cores. Each wire is a separate address line driven by its own transistor.

[WARNING]
====
After weaving, keep the word wire physically separated from the sense
coil leads. Capacitive coupling between the drive wire and sense lines is
the #1 source of false "1" reads on unthreaded cores.
====

'''

=== Step 3 — Build the Transistor Driver

For each word wire:

. Connect the *Collector* of a 2N2222 to one end of the word wire.
. Connect the other end of the word wire to *+5V via a 100Ω resistor*
  (limits drive current to ~30–50 mA for a strong sense pulse).
. Connect the *Emitter* to GND.
. Connect the *Base* to an Arduino digital output pin via a 1kΩ resistor.
. Place a 1N4148 diode with *anode at Emitter, cathode at +5V* for flyback
  protection — do not skip this.

[WARNING]
====
The 2N2222 pinout (EBC order) varies by manufacturer. Check the flat face
of the TO-92 package against your specific datasheet before inserting into
the breadboard. Inserting backwards will not damage the part but will
produce no switching.
====

'''

=== Step 4 — Build the Preamp Stage

For each of the 8 cores (uses *2N3904*, not 2N2222):

. AC-couple the sense coil output through a *100nF capacitor*.
. Connect the cap output to the *Base* of a *2N3904* via a 10kΩ resistor.
. Connect the *Emitter* to GND.
. Connect the *Collector* to +5V via a *4.7kΩ resistor*.
. The Collector output feeds the LM393 (+) input.

'''

=== Step 5 — Build the LM393 Comparator

For each of the 8 cores:

. Connect the preamp Collector to the *(+) non-inverting input* of one
  LM393 channel.
. Build the revised reference divider (3.3kΩ to +5V, 150kΩ to GND) and
  connect the midpoint to the *(-) inverting input*. Add 100nF from (-) to GND.
. Add a *1 MΩ resistor from the LM393 output to its (+) non-inverting input*
  for hysteresis.
. The LM393 output is *open-collector* — add a *10kΩ pull-up* to +5V.
. Add a *100nF decoupling cap* from each LM393 Vcc pin to GND.

The LM393 has 2 channels per chip — you need *4 chips* for 8 cores.

'''

=== Step 6 — Build the Pulse Stretcher (New — Required)

For each of the 8 sense channels:

. Place a *1N5819 Schottky diode* with anode connected to the LM393
  open-collector output (after the 10kΩ pull-up), cathode to Node A.
. Connect a *1nF (102) ceramic capacitor* from Node A to GND.
. Connect a *56kΩ resistor* from Node A to GND (sets stretch to ~56 µs —
  adjust to taste; higher value = longer stretch).
. Connect Node A to *pin 1 of a 74HC14* Schmitt-trigger inverter.
. Connect the output of that inverter (pin 2) to *the next 74HC14 gate input*
  (pin 3). Connect pin 4 to the Arduino sense pin.
. Repeat for all 8 channels. Each 74HC14 chip has 6 inverters = 3 channels
  per chip, so 2 chips cover all 8 channels with 4 gates unused.
. Connect 74HC14 Vcc (pin 14) to +5V and GND (pin 7) to GND with 100nF
  decoupling cap from pin 14 to pin 7.

*Result:* When a sense pulse fires, the Schottky diode quickly charges the
1nF cap. The slow 56kΩ discharge holds the voltage above the 74HC14 Schmitt
threshold for ~56 µs, producing a clean, deterministic stretched output pulse.
The double-inversion restores active-LOW polarity (LOW = bit detected).

[TIP]
====
Test the stretcher in isolation before connecting to the Arduino. Probe
Node A on the scope while manually triggering the word wire. You should
see a fast rising edge followed by an exponential decay over ~50–100 µs.
Adjust the resistor to change the decay time if needed.
====

'''

=== Step 7 — Wire Arduino Pins

....
Word Wire 0 (address 0x00) → Arduino D12 (via transistor driver)

Sense Core 0 (Bit 7)  → Pulse stretcher → Arduino D2  ← INT0
Sense Core 1 (Bit 6)  → Pulse stretcher → Arduino D3  ← INT1
Sense Core 2 (Bit 5)  → Pulse stretcher → Arduino D4
Sense Core 3 (Bit 4)  → Pulse stretcher → Arduino D5
Sense Core 4 (Bit 3)  → Pulse stretcher → Arduino D6
Sense Core 5 (Bit 2)  → Pulse stretcher → Arduino D7
Sense Core 6 (Bit 1)  → Pulse stretcher → Arduino D8
Sense Core 7 (Bit 0)  → Pulse stretcher → Arduino D9
....

[TIP]
====
*First build tip:* Wire only Bit 7 (D2, INT0) first and validate the
entire signal chain — coil → preamp → LM393 → stretcher → Arduino —
before building out the other seven channels. This cuts debugging time
significantly.
====

'''

=== Step 8 — Validate with Oscilloscope Before Coding

With everything wired, probe each stage while manually triggering the
word wire transistor:

*At the sense coil (before preamp):*
* *You should see:* a spike of 200–900 mV, ~200–500 ns wide.
* *Under 50 mV:* wrong ferrite material, or insufficient drive current.
* *Nothing at all:* check coil continuity (~5–10 Ω) and word wire routing.

*At the 2N3904 collector (after preamp):*
* *You should see:* a spike clipping at the +5V rail or saturating at ~0.2 V.
  Either is fine — you just need it to swing >100 mV past the reference.

*At the LM393 output:*
* *You should see:* output snapping LOW for ~1–3 µs when a true-bit pulse
  arrives. Should stay firmly HIGH for a false-bit (no-threading) core.
* *Output flat:* check pull-up to +5V, verify LM393 pinout, lower reference
  (reduce 3.3kΩ to 1kΩ for testing).

*At Node A (after Schottky, before 74HC14):*
* *You should see:* fast rising edge, exponential decay over ~50–100 µs.

*At the Arduino pin (after 74HC14 double inverter):*
* *You should see:* a clean LOW pulse of ~50–100 µs width, one per word-wire
  trigger, only on cores where the wire passes through.

Do not skip this step. Debugging in software when the analog chain is broken
is the most common cause of failed builds.

'''

Upload the Arduino sketch below, open the Serial Monitor at 9600 baud, and
confirm the byte you wove matches what is printed.

== 💻 Arduino Code (Revised)

Key changes from original:

* `digitalRead()` replaced with direct `PIND` port register read (~50× faster)
* OR-accumulate loop samples all 8 bits repeatedly over the 50 µs window
* INT0/INT1 now serve as "valid window" triggers, not sole data capture
* Bit mapping updated for PIND port layout (D2–D7) and PINB (D8–D9)

[source,cpp]
----
// ============================================================
// Core Rope Memory Reader — Revised
// Pulse-stretched sense lines, direct port reads
//
// D2 (INT0) triggers the sample window.
// All 8 bits sampled via PIND/PINB OR-accumulator for full window.
// LM393 + pulse stretcher output is active-LOW.
// Sense pins: D2=Bit7, D3=Bit6, D4=Bit5, D5=Bit4,
//             D6=Bit3, D7=Bit2, D8=Bit1, D9=Bit0
// ============================================================

const int WORD_WIRE_PIN = 12;
const int PULSE_US      = 300;   // word wire pulse width
const int WINDOW_US     = 200;   // OR-accumulate window (>> stretcher decay)
const int LOOP_DELAY_MS = 2000;

volatile bool windowOpen = false;

void isr_windowOpen() {
  windowOpen = true;
}

void setup() {
  Serial.begin(9600);

  pinMode(WORD_WIRE_PIN, OUTPUT);
  digitalWrite(WORD_WIRE_PIN, LOW);

  // Set D2–D9 as inputs (no pull-up — stretcher provides defined logic)
  DDRD  &= 0b00000011;  // D2–D7 as inputs (preserve D0/D1 for Serial)
  PORTD &= 0b00000011;  // no pull-up on D2–D7
  DDRB  &= 0b11111100;  // D8–D9 as inputs
  PORTB &= 0b11111100;  // no pull-up on D8–D9

  attachInterrupt(digitalPinToInterrupt(2), isr_windowOpen, FALLING);

  Serial.println("================================================");
  Serial.println("  Core Rope Memory Reader — Revised");
  Serial.println("  Pulse-stretched sense lines, port reads");
  Serial.println("================================================");
}

byte readWordWire() {
  // Bits captured by OR-accumulating active-LOW signals
  // PIND bit layout: bit7=D7...bit2=D2, bits 1:0 = Serial
  // PINB bit layout: bit1=D9, bit0=D8

  uint8_t dAccum = 0xFF;  // start all HIGH (no bits triggered)
  uint8_t bAccum = 0xFF;

  windowOpen = false;

  // Fire the word wire pulse
  noInterrupts();
  digitalWrite(WORD_WIRE_PIN, HIGH);
  delayMicroseconds(PULSE_US);
  digitalWrite(WORD_WIRE_PIN, LOW);
  interrupts();

  // OR-accumulate port reads over the sample window
  // Active-LOW: a LOW bit means that channel fired
  // We AND-accumulate so any single LOW in the window is captured
  unsigned long start = micros();
  while (micros() - start < WINDOW_US) {
    dAccum &= PIND;
    bAccum &= PINB;
  }

  // Build result byte
  // Active-LOW inversion: bit is 1 where port read was LOW
  uint8_t result = 0;

  // D2=Bit7, D3=Bit6, D4=Bit5, D5=Bit4, D6=Bit3, D7=Bit2
  if (!(dAccum & (1 << 2))) result |= (1 << 7);  // D2 → Bit7
  if (!(dAccum & (1 << 3))) result |= (1 << 6);  // D3 → Bit6
  if (!(dAccum & (1 << 4))) result |= (1 << 5);  // D4 → Bit5
  if (!(dAccum & (1 << 5))) result |= (1 << 4);  // D5 → Bit4
  if (!(dAccum & (1 << 6))) result |= (1 << 3);  // D6 → Bit3
  if (!(dAccum & (1 << 7))) result |= (1 << 2);  // D7 → Bit2

  // D8=Bit1, D9=Bit0
  if (!(bAccum & (1 << 0))) result |= (1 << 1);  // D8 → Bit1
  if (!(bAccum & (1 << 1))) result |= (1 << 0);  // D9 → Bit0

  return result;
}

void printByte(byte val) {
  Serial.print("  Binary : 0b");
  for (int i = 7; i >= 0; i--) {
    Serial.print((val >> i) & 1);
    if (i == 4) Serial.print(" ");
  }
  Serial.print("\n  Hex    : 0x");
  if (val < 16) Serial.print("0");
  Serial.print(val, HEX);
  Serial.print("\n  Decimal: ");
  Serial.println(val, DEC);
}

void loop() {
  byte data = readWordWire();
  Serial.println("------------------------------------------------");
  Serial.println("  Read result:");
  printByte(data);
  delay(LOOP_DELAY_MS);
}
----

== 🧵 Programming Your Memory

To change the stored data, physically re-weave the word wire:

* *Store a 1* → thread the wire through the center hole of the core
* *Store a 0* → route the wire around the outside of the core

To store multiple bytes, wire an additional transistor driver per word wire
to a new Arduino output pin. Extend the sketch to pulse each address line
in sequence and print each result.

== 🐛 Troubleshooting

|===
|Symptom |Likely Cause |Fix

|All bits read as 0
|No sense signal reaching Arduino
|Probe sense coil with scope — check coil continuity first

|All bits read as 1
|Word wire coupling into all sense lines capacitively
|Route word wire away from sense leads; use twisted sense pair

|Weak/no spike on scope (<50 mV at coil)
|Wrong ferrite material or too little drive current
|Confirm cores are grey/black type 43 — not iron-powder (red/yellow/mixed)

|Spike present but LM393 output flat
|Reference too high, or LM393 wiring error
|Lower reference (swap 3.3kΩ for 1kΩ temporarily); verify LM393 pinout

|LM393 output fires but stretcher output flat
|Schottky diode installed backwards, or 74HC14 not powered
|Check diode orientation; verify 74HC14 Vcc and GND connections

|Correct bits but wrong order
|Bit index inverted in firmware
|Swap the PIND/PINB bit-to-result mapping in readWordWire()

|Intermittent reads on some channels
|Stretcher RC too short for sample window
|Increase discharge resistor (e.g. 56kΩ → 220kΩ) to extend stretched pulse

|Random false 1s on unthreaded cores
|Capacitive coupling from word wire; or stretcher too sensitive
|Twist all sense leads; physically separate word wire; increase LM393 reference slightly

|Transistor not switching
|Wrong 2N2222 or 2N3904 pinout for your specific brand
|Pinout varies — verify EBC order on your datasheet's flat-face diagram

|LM393 output chatters (oscillates) at threshold
|Missing hysteresis resistor
|Add 1MΩ from LM393 output to (+) input as specified in Step 5

|Magnet wire end has no continuity to breadboard
|Enamel not fully removed
|Sand more aggressively; test stripped end with multimeter before inserting
|===

[NOTE]
====
*Scope rule:* Clean 200+ mV spike at sense coil but LM393 output flat
→ problem is in the comparator circuit (threshold, pull-up, pinout, hysteresis).
Spike present, LM393 fires, but Arduino reads 0 → problem is in the stretcher
or pin mapping.
No spike at all → mechanical problem (coil winding, word wire routing,
wrong ferrite material).
====
